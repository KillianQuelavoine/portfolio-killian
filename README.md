# Portfolio — Killian Quelavoine

Portfolio statique, responsive et prêt à être déployé gratuitement sur Vercel.

## Pages

- `/` : landing page avec showreel, projets sélectionnés, présentation et contact.
- `/works/` : grille filtrable des projets de cadrage et de montage.

## Prévisualisation locale

Ouvrir `index.html` dans un navigateur. Aucun build ni dépendance n'est nécessaire.

## Déploiement Vercel

Importer le dépôt GitHub dans Vercel. Le projet est un site statique et ne nécessite aucune variable d'environnement.
